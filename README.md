# DeepSeek OpenAI API Example

This Python script demonstrates how to interact with a DeepSeek model using an OpenAI-compatible API endpoint. It sends a prompt and prints the model's generated response, showcasing a unified approach to LLM integration.

## Language

`python`

## How to Run

1. Set DEEPSEEK_API_URL, DEEPSEEK_MODEL_NAME, and optionally DEEPSEEK_API_KEY environment variables.
2. Run the script: python main.py
